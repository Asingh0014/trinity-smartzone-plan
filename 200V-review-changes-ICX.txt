! VLAN mapping (from the Review comments)
!   1240 (200V_staff ) -> 2100 (VL-staff-wired-01)  16 ports
!    100 (management ) -> 2000 (VL-netmgmt-01    )   2 ports
!    230 (Library    ) -> 2530 (VL-library-01    )   2 ports
!
! Not in this file
!   - Review section 4 (items 63-72): 'GC - leave the VLAN as they are'
!   - Review section 3 items with no target VLAN in the Comments column
!     (21, 22, 24, 26, 27, 35-42, 44, 47-53, 62): still to be identified
!   - Review section 1 (items 1-14): already moved in the 9 Oct cutover
!
! Before starting
!   - VLANs 2000, 2100 and 2530 already exist on every switch here and are
!     tagged on its uplink (lag 10 on lv3/lv4/lv6; 1/1/12 on LT2-3, carried
!     through LT2-1 1/1/24). The core has ve 2000 (10.21.0.0/24), ve 2100
!     (10.21.3.0/24) and ve 2530 (10.21.24.0/24) with DHCP helpers
!   - Trinity to confirm DHCP on 10.21.3.0/24 (staff), 10.21.24.0/24 (library)
!     and 10.21.0.0/24 (netmgmt)
!   - lv3 1/1/48 and lv4 1/1/48 (MACs 00:09:F5, same vendor as the two devices
!     behind switch-200V-8): move to 2000 only if the device uses DHCP or is
!     re-addressed into 10.21.0.0/24. With a static 192.168.122.x address it
!     will be unreachable after the move
!
! Same method as the cutover: CHANGE removes the old untagged VLAN first, then
! adds the new one. Tagged VLANs are not touched (lv6 1/1/31 keeps 1272 and
! 1273 tagged; LT2-3 1/1/4 keeps 100 tagged). PORT BOUNCE makes DHCP devices
! renew; it does not remove PoE.
! Per switch: PRE-CHECK > CHANGE > PORT BOUNCE > VERIFY > write memory.
!=============================================================================

!=============================================================================
! switch-200V-LT2-3  (192.168.122.14)  -  1 ports
!=============================================================================
!
! Port list (Review item, old -> new, MAC seen)
!   1/1/4    1240 -> 2100  item 23  d4a2.cde1.dd0e
!
!-----------------------------------------------------------------------------
! switch-200V-LT2-3 PRE-CHECK (exec mode, read-only)
!-----------------------------------------------------------------------------
show vlan 1240
show vlan 2100
show mac-address ethernet 1/1/4
! Expect each MAC in the port list on its port, on the old VLAN
!
!-----------------------------------------------------------------------------
! switch-200V-LT2-3 CHANGE
!-----------------------------------------------------------------------------
configure terminal
vlan 1240
 no untagged ethernet 1/1/4
 exit
vlan 2100
 untagged ethernet 1/1/4
 exit
end
!
!-----------------------------------------------------------------------------
! switch-200V-LT2-3 PORT BOUNCE
! Paste part 1, wait 10 seconds, then paste part 2
!-----------------------------------------------------------------------------
! Part 1
configure terminal
interface ethernet 1/1/4
 disable
 exit
end
! Part 2 (after 10 seconds)
configure terminal
interface ethernet 1/1/4
 enable
 exit
end
!
!-----------------------------------------------------------------------------
! switch-200V-LT2-3 VERIFY
!-----------------------------------------------------------------------------
show vlan 2100
show mac-address ethernet 1/1/4
! Expect: each port untagged in its new VLAN, and its MAC learned on the new VLAN
! Then save:
write memory
!
!-----------------------------------------------------------------------------
! switch-200V-LT2-3 ROLLBACK (only if needed)
!-----------------------------------------------------------------------------
configure terminal
vlan 2100
 no untagged ethernet 1/1/4
 exit
vlan 1240
 untagged ethernet 1/1/4
 exit
end
! Then run the PORT BOUNCE again and write memory
